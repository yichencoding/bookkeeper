## 部署（选一种，5 分钟）
### 最简单：Netlify Drop
1. 打开 https://app.netlify.com/drop ，把整个 `standalone-app` 文件夹拖进去。
2. 得到一个 `https://xxx.netlify.app` 网址，发给家人就能打开。
3. 手机上用 Safari / Chrome 打开 → 分享 → 添加到主屏幕，就跟 App 一样。

### 或者：Vercel
1. 在 https://vercel.com 注册登录，New Project → 上传这个文件夹（或推到 GitHub 后导入）。
2. 部署完成后得到公开网址。

### 或者：GitHub Pages
1. 新建公开仓库，把 `index.html` 推到根目录。
2. Settings → Pages → Source 选 main 分支，得到 `https://<用户名>.github.io/<仓库>/`。

## 接 Google Sheets 同步（3 步，约 10 分钟）
1. 打开你的 Google Sheets《家庭记账》（ID：1tEkzTsXW3GMZ-J1DBwjWyOYVAG_qNX54S7GcDeShaVU），确认有「所有交易」tab，第 1 行是 9 列标题。
2. 在 Sheet 里点 扩展程序 → Apps Script，把 `Code.gs` 全部粘贴进去，把 `SYNC_SECRET` 改成你自己的密钥（默认 `jia-ting-2026`，记得改掉）。
3. 点 部署 → 新建部署 → 类型选 Web 应用 → 执行身份选「我」→ 访问权限选「任何人」→ 部署，复制网址。
4. 打开 App → 同步设置，填网址和密钥，点「从 Sheet 拉取」验证一次。成功后点「推送到 Sheet」。

注意：Apps Script 的网址是公开可访问的，安全靠 SYNC_SECRET，不要把密钥发给不信任的人。Sheet 本身的分享权限在 Google Drive 里控制：只想让家人看就给查看者，只想让家人记就给编辑者。

## 家人怎么用
- 发部署好的网址给家人，他们不用装任何东西、不用登录 Muse，打开就能记账。
- 每个人打开的是同一个 App，数据以 Google Sheets 为准：记完点「推送到 Sheet」，别人点「从 Sheet 拉取」就能看到。
- 如果两个人同时改同一笔，以最后一次推送为准。建议：记完就推送，打开先拉取。

## 导入 / 导出
- App 里支持导入 / 导出 .xlsx 和 .csv，格式就是模板的 9 列，重复按交易ID（或日期+商家+金额）自动跳过。
- 直接在 Sheet 里改也行，下次打开 App 点拉取就会同步回来。
